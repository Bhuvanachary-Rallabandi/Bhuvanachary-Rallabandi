### 🚀 Featured Projects

**[CAN-Based Automotive Dashboard](https://github.com/Bhuvanachary-Rallabandi/can-automotive-dashboard)**
Real-time ECU simulation across 3 nodes on a PIC18F4580, with register-level CAN configuration, acceptance filtering, and interrupt-driven message handling.
`Embedded C` `CAN Protocol` `PIC18F4580` `Interrupt-Driven Design`

**[CAR Black Box](https://github.com/Bhuvanachary-Rallabandi/car-black-box)**
6-state FSM event logger capturing speed, gear, and RTC timestamps to internal EEPROM — with debounced keypad handling and write-protected atomic storage.
`Embedded C` `I2C` `UART` `EEPROM`

**[MINISHELL](https://github.com/Bhuvanachary-Rallabandi/minishell)**
Unix shell interpreter handling 30 built-in and 152 external commands, multi-stage pipe routing via `dup2`, and full SIGINT/SIGTSTP job control.
`C` `System Calls` `IPC` `Signal Handling`

**[Inverted Search Engine](https://github.com/Bhuvanachary-Rallabandi/inverted-search)**
Command-line search tool building a hash-table-based inverted index across text files, with O(1) lookup and incremental updates without rebuilding.
`C` `Hash Tables` `Linked Lists` `File I/O`

**[Arbitrary Precision Calculator](https://github.com/Bhuvanachary-Rallabandi/arbitrary-precision-calculator)**
Big-integer arithmetic engine using doubly linked lists for digit-wise carry/borrow propagation, with full sign and edge-case handling.
`C` `Doubly Linked Lists` `Dynamic Memory`

**[LSB Image Steganography](https://github.com/Bhuvanachary-Rallabandi/lsb-steganography)**
CLI tool that hides and extracts text in BMP images via least-significant-bit encoding, with capacity checks and magic-string detection.
`C` `Bitwise Operations` `BMP Parsing`
